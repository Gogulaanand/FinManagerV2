# Phase Briefings

One file per completed phase: `phase-N.md`, 100-200 lines max.

Each briefing must contain:

1. What was built: bullet points with exact file paths.
2. The union of all files touched during the phase.
3. The next phase's section copied verbatim from PRODUCTION_PLAN.md.

A new session starting phase N reads `phase-(N-1).md` and only the files it lists, skipping broad codebase scanning.
